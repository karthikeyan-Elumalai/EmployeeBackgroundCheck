If REPORT_GENERATION_MODE=ollama, FastAPI sends the prompt to the local /api/generate endpoint. If Ollama fails or returns empty, the template report is used automatically.

9. related corpus snippets

Return payload from /upload: case_id, filename, verification, assessment, external_verification, resume_insights, report_generation, report, and OCR payload. The /report route uses the same pipeline but omits the OCR payload.
